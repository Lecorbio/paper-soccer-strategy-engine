# Topology challenger

This candidate starts byte-for-byte from the immutable `rank_5` engine. Its
single experiment is capped rebound-goal connectivity used only for move
ordering. Near a goal shell, when the opponent can score with zero or one fresh
landing, edges that break that corridor are searched before edges that preserve
it. The replay book, learned value anchor, evaluation scores, clocks, mate
claims, and general alpha-beta search remain unchanged.

Promotion evidence is owned by `../../promotion/`. A candidate is submission-
worthy only after the initial sentinel, disjoint development/validation/test
banks, generated-artifact tests, timing distribution, and source-size checks
all pass the frozen manifest. Raw wins against `rank_5` alone are diagnostic,
not promotion evidence unless they come from the predeclared paired,
source-game-clustered elite banks and clear every stage threshold.
