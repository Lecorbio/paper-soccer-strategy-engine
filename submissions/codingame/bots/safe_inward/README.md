# Safe-inward rebound experiment

This candidate starts from the immutable `rank_5` bot and changes only move
ordering. In the mover's own goal shell, a nonterminal inward edge receives a
small priority when it lands on a rebound point and therefore continues the
turn.

The frozen T2 hypothesis and result are recorded in `EXPERIMENTS.md`. The
candidate was rejected by the development gate and must not be submitted.
