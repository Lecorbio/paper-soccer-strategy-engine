Methodology in brief

The test tournament uses disjoint frozen openings at four depths. Each opening is played twice with colors swapped, and profile selection is frozen before the final tournament.

Interpretation notes

Scope and limitations

  • Rank5Derived is an adaptation of the original submission to the demo rules.
  • Its 50% validation strength is a defined reference, not an observed score.
  • Relative-strength estimates only compare entrants in this tournament.
  • Latency depends on the benchmark machine and build.
